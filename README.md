# Pixel UI Free

**A free pixel-art GUI theme for Godot 4.** Set it in Project Settings and every Button, slider,
tab, checkbox and window in your game takes it on. No 9-slice setup and no styling by hand.

### Want more?

**[Pixel UI](https://heyheythere.itch.io/pixel-ui)** has six colour themes (stone, wood, sky, forest, royal and ember) and
50 icons: food, bombs, elements, trophies, locks, and a full menu set with sound, music, settings,
save and delete. Same files and names: install it over this one.

### What's inside

- **The wood theme** as a Godot `Theme` resource: buttons (normal, hover, pressed, disabled), option
  buttons, checkboxes and radio buttons, sliders, progress bars, tabs, text fields, panels, windows
  with title bars, sunken item slots, tooltips, popup menus and scroll bars.
- **20 icons**, 16x16 and outlined: hearts (full, half, empty), coin, gem, key, potion, sword, shield,
  chest, star, bag, check, cross, arrows, info, user, play and pause.
- **A pixel font** with all of printable ASCII, as a BMFont that Godot reads directly.
- **Health, mana, stamina and XP bar fills**, and a mouse cursor at 1x to 4x.
- Everything is also a plain PNG, so it works in any engine.

### Compatibility

- Godot **4.3 to 4.7**, tested on both ends.
- **Forward+, Mobile and Compatibility** renderers.
- No scripts needed: the theme is a plain resource.

### Install

Copy `addons/pixel_ui/`, set *Default Texture Filter* to **Nearest**, and choose
`themes/wood.tres` under *GUI > Theme > Custom*. `addons/pixel_ui/README.md` has the details.
